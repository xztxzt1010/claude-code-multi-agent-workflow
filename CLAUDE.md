# Project instructions

- Treat this repository as a public artifact. Never add credentials, local permission allowlists, private transcripts, hidden reasoning, or machine-specific absolute paths.
- Keep the six agent names and their output keys stable unless the evaluation set and migration notes are updated together.
- Run `npm test` after changing agents, skills, evaluation cases, install scripts, or documentation links.
- Behavioral claims require recorded evaluation evidence under `evals/results/`; static validation alone is not evidence of quality improvement.
- Destructive operations, publishing, production writes, and external messages require explicit human approval.
